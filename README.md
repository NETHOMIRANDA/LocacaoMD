# MD Locacoes - Vistorias

App web para controle de vistorias de veículos da MD Locações.

## Deploy Gratuito (PythonAnywhere)

1. Criar conta em https://www.pythonanywhere.com (gratuito)
2. Upload do zip na aba "Files"
3. Extrair
4. Configurar web app Flask
5. URL permanente: https://SEU_USUARIO.pythonanywhere.com
